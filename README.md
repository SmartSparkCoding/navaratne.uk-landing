# navaratne.uk

The front door to navaratne.uk: a plain, static directory of every site, tool and
download Jacob has put on the internet.

- `index.html` — the page. All links are written by hand, no JavaScript.
- `style.css` — one stylesheet, with a light and a dark theme.
- `favicon.svg` — the little square in the tab bar.
- `CNAME` — tells GitHub Pages to answer for `navaratne.uk`.

Served by GitHub Pages from `main`. No build step, no dependencies: edit the
HTML, commit, done.
